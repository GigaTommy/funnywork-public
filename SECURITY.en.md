# Reporting security issues

[简体中文](SECURITY.md) | **English**

Report security issues privately to [support@funnypixelsapp.com](mailto:support@funnypixelsapp.com). Include the source commit or application version, platform, required configuration, reproduction steps, and impact. Use synthetic data and redact accounts, tokens, keys, and personal information from attachments.

Reports may cover servers, desktop and mobile clients, and dependencies. Maintainers investigate and coordinate fixes, releases, and disclosure timing. Downloads and upgrades are available through the [website](https://funnywork.funnypixelsapp.com).

Revoke or rotate exposed credentials before removing copies from source, history, and logs. Public Issues are suitable for ordinary defects with sensitive details removed. Use the private channel above for unpatched attack steps or real user data.
