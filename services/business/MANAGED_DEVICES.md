# 成员设备管理

管理端客户端页面提供成员设备清单。设备来自桌面同步注册；执行节点和远程控制授权继续由各自入口维护，不混用标识和状态。

## 权限与查询

GET `/api/v1/desktop-devices` 需要管理端 `funnyworker:client:read` 权限及业务 ADMIN 身份。只返回当前租户、成员全部业务区域都在管理员范围内的设备，停用成员仍可由有范围权限的管理员维护。返回成员显示名、设备名称、系统、注册和上报时间、访问版本等运行信息，不返回对话内容、状态正文、工作区路径或命令载荷。

参数 `query` 按设备或成员显示名搜索，百分号和下划线按普通字符处理；`state` 接受 ALL、ONLINE、OFFLINE、REVOKED。每次最多扫描 100 个匹配搜索条件的设备，通过 `after` 和 `hasMore` 继续读取。权限与状态过滤可能产生空页，有后续游标时仍可继续查询，不把当前列表数量显示为组织总数。

在线要求账号启用、设备未撤销、有运行标识，并在服务端观察时间前 30 秒内收到运行状态。注册和历史上传记录分别保存，在线状态按当前运行上报判断。界面标明状态截至时间，刷新重新获取。客户端上报版本、模型下发及最后加载版本、组织策略下发及最后应用版本通过同一账号设备关联显示。未上报、运行设置不匹配、等待确认、等待更新和过期分别展示；回执记录客户端报告的配置状态；硬件身份和模型推理结果分别检查。数据库发布版本或有效部署文件版本参与目标比较；无法读取有效配置时明确显示目标未知，不把已确认下发版本误称为组织最新版本。

## 撤销与恢复

POST `/api/v1/desktop-devices/{id}/revoke` 与 `/restore` 需要 `funnyworker:client:write`、业务 ADMIN 身份及设备所属成员的全部区域权限。请求携带 `revision`，过期版本拒绝写入。事务按租户、成员、设备顺序锁定，共用现有设备访问状态变更逻辑。

撤销后拒绝该设备同步与远程控制，排队命令过期，已领取命令标记为结果不确定且不会自动重放。撤销保留本地数据和成员其他登录会话；已开始的本地操作需在原电脑确认并停止。恢复清空旧运行状态，等待新的上报，不恢复过期命令。状态实际变化记录管理员、成员、设备和访问版本审计；重复提交当前状态不增加版本或重复审计。

V77 为按租户和设备标识分页增加索引，不修改既有数据。自动测试覆盖隔离、范围、在线真实性、分页、字面搜索、版本冲突、撤销与恢复、真实 HTTP 权限及请求校验；旧同步流程继续回归。生产迁移和管理界面实测仍需在发布验收阶段完成。

V78 增加模型下发及运行回执。签名摘要绑定具体下发包，重新下发后需要重新确认；更换设备公钥会清除旧应用回执。关联模型设备与同步设备前校验相同租户、相同账号及同步设备未撤销，唯一关系避免同一同步设备重复出现在列表中。策略回执通过该关联读取，不能按账号将不同设备的回执混用。

## 历史归集元数据

设备列表和详情增加 `historySessionCount`、`historyEventCount`、`historyLastUpdatedAt`。仅对当前页已通过权限与筛选的设备执行一次按租户限定的会话聚合，不逐设备请求、不扫描原始事件。事件数量来自持久化游标，含分叉中实际保存的继承事件，不是去重后的员工问答次数。最近更新取会话元数据更新时间，已上传范围通过服务端归集游标核对。没有记录时数量为零、时间为空。

此入口继续只返回操作元数据，不新增管理员正文读取权限，也不暴露标题、本地目录、原始事件或附件内容。
