# 完整应用与私有推理部署 UAT 操作脚本

本文件在独立测试租户与测试设备执行。执行前阅读 [测试方案](MODEL_UAT_PLAN.md)，填写环境和账号矩阵；未实际执行的项目标记 NOT_RUN，不使用模拟结果代签。以下步骤不要求生产账号、密钥或网络安全策略变更。

## 记录模板

每个用例复制：`ID / OS或浏览器 / 安装包与源码版本 / 引擎与模型版本 / 匿名账号与zone / 前置状态 / 操作时间 / 实际结果 / 状态 / 截图路径 / 票据或逻辑调用标识 / 缺陷编号 / 执行人`。测试凭证由测试负责人在本机环境配置，不写入本文件。

每组在macOS与Windows测试安装包分别执行。新旧行为验证使用不同账号私有测试目录，不能删除真实用户文件。选择、标题、压缩、工具及子任务关联应从调用票据核对，不凭客户端文案推断。

| --- | --- | --- |
| N01 | 新测试账号，入口开关关闭/旧服务bootstrap404；登录并打开原模型菜单 | 保留已验证的旧行为，不错误进入企业模式；不调用私有入口 |
| N02 | 开启企业模式、发布两个模型；新账号登录；选择Qwen再选择DeepSeek并分别发起测试任务 | 现有选择UI复用；目录仅含授权项；实际票据模型与选择一致；上游密钥不下发 |
| N03 | 空目录登录；随后发布模型，等待目录刷新再打开选择 | 空态明确且无公网回退；目录更新可见。若旧默认指向已下线模型，选择新模型后可继续，不默默换模型 |
| N04 | 用受管任务及标题/压缩/子任务分别产生请求；核对入口账本与推理服务访问日志 | 每次模型调用有票据；共享池限额包含辅助调用；本地工具执行阶段不占推理许可。GPU网络入口是否仅允许网关需由部署方另行验证 |
| N05 | 执行上限1：U1运行，U2提交；等待超过流式空闲超时；再让U1完成 | U2显示排队，可取消；等待不被误判推理超时；获得许可后正确推理，未重复提交 |

| N08 | 运行或UNKNOWN状态关闭Host/重启应用，同一请求恢复 | 不自动重放；明确需要核对/恢复；不生成第二次推理消耗 |
| N09 | 一个长任务跨工具调用、多轮推理；同时标题与压缩请求 | 各轮独立准入与计量；任务关联可核对；不是整段任务持有名额 |
| N10 | 使用8192上下文/2048输出模型；逐步堆积对话触发自动压缩，再手动压缩 | 默认压缩可工作；摘要输出不超过有效限制；摘要记录实际预算；没有因65536默认值拒绝请求 |
| N11 | 存在显式过大的压缩/输出配置，或切换小模型但历史已超限 | 明确配置/能力错误，不能隐藏失败或伪造成功；不擅自改写用户显式策略 |
| N12 | 单用户提交多个主/子任务，同时另一成员提交 | 每人执行/等待限制生效；员工轮转无永久饥饿；排队位置仅参考，不承诺固定名次 |
| N13 | 在排队/运行时撤销用户/zone；停用账号D；尝试后续请求 | 派发前再次拒绝；运行连接收到停止请求；短期入口凭证不能绕过当前授权 |

| N18 | 多轮工具任务中切换模型（空闲时）、重启应用再继续 | 多轮工具关联、推理回放和模型选择持久化与契约一致；不因切换伪造历史 |

| ID | 操作步骤 | 必须核对的结果 |

| E02 | 普通非流式、流式；检查头部、分块、结束事件和最终usage | 内容原样；首字/结束状态正确；缺失usage明确未知 |

| E04 | 工具参数跨多个流片段、长参数、空参数、模型自行不用工具、非法参数 | 增量拼接正确；非法结果可见且不误执行工具 |

| F08 | 测试库快照恢复，切换恢复世代；旧副本仍尝试派发或回写 | 旧进程被恢复栅栏拒绝；新服务不重复执行；凭证/授权符合恢复策略 |

## 缺陷与签字

不可接受：越租户/越区读写、超发、恢复重放、错误零计量、未知执行自动释放、企业账号静默公网回退、页面无法取消/恢复。出现上述问题标P0/P1，保存最小匿名证据并停止该场景扩展。

签字分开填写：源码回归负责人、页面UAT负责人、macOS安装包、Windows安装包、若依权限联调、每组实际引擎/模型、运维多副本恢复。任何NOT_RUN保留到最终结果，不用其他环境结果替代。
