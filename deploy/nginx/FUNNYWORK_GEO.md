# 官网搜索与内容索引

本页供官网内容、前端和运维人员维护搜索入口。官网地址统一写为 [https://funnywork.funnypixelsapp.com](https://funnywork.funnypixelsapp.com)，产品页面使用“官网”作为入口文案。

## 内容与页面关系

产品介绍按用户任务组织，包含资料整理、数据分析、成果阅读和多端协作。中英文页面表达相同事实，截图和视频使用对应语言的实际客户端素材。

页面标题、描述、canonical、hreflang 和结构化数据由站点构建配置维护。新增页面或调整路径时，同步核对页面导航、语言映射、sitemap 和 robots 规则。部署域名与各语言规范地址按目标环境配置生成。

## 构建与检查

站点生成入口为 `scripts/build/build-site-geo.cjs`。使用已审核的目标站点配置和下载清单生成候选资源，输出到 `.local/releases/`；具体环境参数由运维人员提供。

1. 检查生成页面的标题、正文、图片替代文本、结构化数据和所有站内链接。
2. 检查 robots 允许公开页面抓取，私有业务路径继续受鉴权与访问规则控制。
3. 核对 sitemap 中的页面可访问、语言关系正确，canonical 指向已发布的规范页面。
4. 在桌面和手机检查正文排版、导航、媒体预览、下载及客服入口。
5. 发布后检查正式 URL 和缓存内容，并在已授权的搜索平台账号中查看抓取、索引及检索记录。

自动化检查使用 `scripts/checks/check-site-release.mjs` 和官网交互检查入口。发布资源清单和操作步骤见[官网维护](../../designs/funnywork-site/README.md)，历史发布与回退记录由私有运维资料保存。
