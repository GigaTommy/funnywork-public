# 区域接入

[官网](https://funnywork.funnypixelsapp.com)提供产品介绍、安装包和联系入口。部分区域通过当地云服务跳转接入，客户端自动选择可用连接。自建服务使用管理员提供的 HTTPS 地址。

## 配置职责

区域接入由运维人员维护，具体节点、服务商、连接凭据和发布记录保存在私有运维资料中。客户端与管理服务通过各自的身份和权限配置接入；数据库与 Redis 保持在服务端私有网络。

服务配置需支持账号认证、聊天流、对话同步、附件传输和提醒注册。聊天流关闭响应缓冲并配置足够的读取超时，上传与下载按接口要求支持分块、摘要和 Range。接口要求见[桌面同步](../../services/business/DESKTOP_SYNC.md)与[手机聊天](../../apps/ios/MOBILE_CHAT.md)。

## 发布与核对

1. 记录当前版本、配置摘要和恢复方法，备份本次授权修改的配置与资源。
2. 在目标环境核对 HTTPS 证书、访问控制、超时和静态资源路径，预览并审核配置差异。
3. 配置校验通过后按既有发布流程切换，保留后台访问规则、客户端 API 和更新通道。
4. 分别检查官网页面、安装包下载、账号登录、模型回复、手机连接及文件传输；使用目标区域的实际设备检查连接体验。
5. 出现异常时按本次备份恢复配置和静态资源，核对服务及客户端连接。

安装包、签名清单及升级流程见[客户端发布与升级](../CLIENT_RELEASES.md)。
