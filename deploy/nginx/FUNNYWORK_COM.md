# 官网部署

官网地址：[https://funnywork.funnypixelsapp.com](https://funnywork.funnypixelsapp.com)。静态资源和交互由[官网维护指南](../../designs/funnywork-site/README.md)管理，安装包与签名清单按[客户端发布与升级](../CLIENT_RELEASES.md)维护。

## 静态资源发布

1. 按发布清单准备页面、样式、脚本及被引用的中英文媒体，核对文件摘要和相对路径。
2. 备份目标环境当前资源及受影响配置，再上传新版本。服务器路径和连接方式按私有运维配置执行。
3. 保留现有 TLS、安全响应头、管理端鉴权、客户端 API 及下载规则，配置检查通过后切换静态版本。
4. 检查页面语言切换、图片、视频 Range、客服草稿、安装包下载与已登录客户端流程。
5. 恢复旧版本时核对本次备份和目标版本，保留已发布安装包及新产生的业务数据。

缓存更新需覆盖本次修改的页面与资源；发布后分别检查页面内容和静态资源摘要。区域接入方式见[区域接入](FUNNYWORK_CN.md)。
