# FunnyWork 使用指南

**简体中文** | [English](USER_GUIDE.en.md)

FunnyWork 用于整理资料、分析数据、生成文档，并通过手机跟进电脑上的任务。电脑端在选定工作区内使用文件和工具；手机提供独立聊天，以及查看、补充和控制电脑任务的入口。

## 选择使用方式

| 要完成的工作 | 使用入口 | 准备条件 |
| --- | --- | --- |
| 文字问答、讨论思路 | 手机菜单中的“聊天” | 已登录、存在可用模型和额度；电脑可离线 |
| 整理本机资料、生成文件、操作网页或电脑 | 电脑端的新对话 | 已打开工作区、可用模型及相应工具权限 |
| 在手机发起或继续电脑上的工作 | 手机菜单中的“远程” | 电脑在线、同一服务和账号、组织允许跨设备访问与远程控制 |
| 阅读已同步的任务记录和文件 | 手机的远程对话 | 联网读取服务端记录；离线时可阅读已缓存内容 |

工作区是任务使用的电脑目录。手机“远程”页中选择的电脑和工作区决定文件读取及工具执行的位置。

## 安装与登录

1. 从 [官网](https://funnywork.funnypixelsapp.com/download/?lang=zh)或管理员提供的分发入口选择对应系统的安装包。iOS 使用下载页提供的 TestFlight 邀请。
2. 安装并打开 FunnyWork，输入账号和密码登录。企业内部署使用管理员提供的账号；手机在登录帮助中配置企业 HTTPS 服务地址。
3. 手机和电脑使用同一服务、组织及账号登录。登录后核对账号名称，并在电脑打开要处理的工作区。

登录失败时核对账号、密码和服务连接提示；账号无权限或模型列表为空时联系管理员开通。安装时出现发布者或签名异常，先向分发方核对安装包。

## 在电脑上完成第一项任务

1. 打开工作区并创建新对话，选择管理员提供的模型和所需能力组合。
2. 将资料放入工作区，或通过对话的附件入口添加资料；在消息中说明要使用的文件。
3. 输入目标、处理范围和成果要求。例如：“读取工作区中的本月销售表，按区域比较营收与目标，生成趋势图，并将说明文档保存到工作区。”
4. 发送后查看回复和工具活动；出现批准或问答请求时，核对操作内容后作出选择。
5. 任务回复后打开生成文件，检查数据、格式和保存位置。需要修改时在同一对话中说明具体意见。

使用浏览器操作前，电脑需安装 Chrome、Edge、Chromium 或 Brave。任务使用独立的可见浏览器窗口；需要登录网站时，在该窗口手动登录。macOS 电脑操作需要在系统设置中授予 FunnyWork“辅助功能”权限，截图功能另需“屏幕录制”权限。Linux 本地预览提供浏览器操作；系统桌面控制适用于 macOS 和 Windows。

工具返回缺少浏览器或权限时，按提示补齐条件后继续任务。普通文字问答可继续使用。

## 在手机上独立聊天

1. 打开左侧菜单，选择“聊天”，点击新对话入口。
2. 在输入区选择可用模型，输入内容并发送。
3. 阅读回复；需要中止生成时点击“停止”，再核对当前对话状态。
4. 从菜单重新打开历史对话继续交流。模型选择作用于后续请求。

手机聊天提供文字输入；需要处理电脑文件或执行工具时，切换到“远程”并选择电脑任务。

## 连接电脑并创建远程任务

### 查看可用电脑

1. 在电脑打开 FunnyWork、登录并保持联网，确认工作区已打开、同步已开启。
2. 在手机左侧菜单进入“设备”，查看电脑名称、连接状态和工作区，刷新后确认设备在线。
3. 电脑离线时回到电脑检查网络、账号和客户端运行状态，再在手机刷新。没有工作区时，先在电脑打开工作区。

iOS 还提供扫码连接：在电脑菜单选择“连接手机”，在 iOS 的“设备 → 连接设备”中扫描二维码，核对电脑名称后点击“连接”。二维码过期时在电脑重新生成。Android 使用设备列表选择同账号电脑。

### 创建并发送

1. 在手机菜单切换到“远程”，点击新对话入口。
2. 选择电脑和工作区，填写任务内容；有模型或预设选项时按任务需要选择。
3. 点击“创建对话”。打开新对话后，核对带入的草稿及执行位置，再点击“发送”。
4. 查看任务回复、处理状态或待办事项，确认电脑已开始处理。

创建对话后内容先保留为草稿，点击发送才提交任务。创建或发送出现“结果待确认”时，点击“核对结果”读取原请求状态；恢复连接后再决定是否重试，避免同一工作重复执行。

## 添加资料、批准操作与停止任务

在电脑任务的输入区添加文件。iOS 从加号菜单选择“照片”“添加文件”或“拍照”；Android 使用“添加文件”选择系统文件。检查附件名称和上传状态，再与文字一起发送，也可只发送附件。手机电脑任务每条消息最多 4 个附件、合计 32 MiB；超出时拆分资料或在电脑工作区中处理。

出现“需要你的批准”时，展开对应请求并查看操作内容，选择允许或拒绝；出现“需要你的回答”时，填写选项或文字并提交。提交后等待状态刷新，已由另一端处理的事项会在刷新后移除。

任务执行中可以继续发送补充内容。需要停止时，在该电脑任务输入区点击“停止”，等待操作回执并核对状态；手机关闭页面后电脑继续运行。断网导致停止结果待确认时，恢复连接后先核对原操作，必要时在电脑端确认并停止。

## 查找和整理对话

- 打开左侧菜单的搜索入口，输入标题关键词。远程搜索还提供消息搜索，可按回复正文或附件名称查找，打开命中结果查看上下文。
- 手机聊天历史提供重命名和归档操作；iOS 通过长按对话进入菜单，Android 使用聊天条目的操作入口。
- 从“已归档”查看并恢复归档对话。归档用于整理目录，电脑上的执行状态需在任务内单独核对。
- 长对话向上查看历史；有新消息时使用返回最新位置的入口继续阅读。离线阅读范围为该设备已保存的记录。

消息搜索需要联网，查找范围为已同步消息及附件名称；查找附件正文时，将文件交给电脑任务处理。

## 查看成果并提出修改

1. 打开对应电脑任务的文件入口：iOS 使用“对话文件”或成果卡片，Android 使用“结果文件”及消息中的文件入口。
2. 核对文件名、版本和同步状态。文件已同步后下载并打开；电脑尚未上传时，保持电脑联网后重试。
3. 图片可直接查看；报告 PDF 预览需要电脑生成并同步预览文件。需要继续编辑时，保存或分享原文件，使用兼容应用打开。
4. 需要修改回复或代码时，打开回复的审阅入口（iOS 为“审阅结果”，Android 为“审阅”），填写意见；diff 内容可选择文件和行引用。点击“加入草稿”，检查合并后的内容，再发送给电脑。

审阅意见加入草稿后由用户确认发送。Android 的“重试预览”也先将请求加入草稿；iOS 提供结果阅读与反馈入口。重新生成的成果使用新版本，阅读旧卡片时仍显示原版本。

预览准备中可等待后刷新；预览失败时先下载原文件。出现字体替换或分页异常，可要求电脑使用已安装字体重新生成预览。已经下载的文件可在离线时打开。

## 账号、提醒和存储

在菜单底部进入账号与设置，调整浅色、深色或跟随系统的外观，查看额度及下载文件占用。点击头像选择图片，预览并保存；其他客户端联网刷新账号资料后显示更新。

iOS 在账号设置的“提醒”中选择需要批准、需要回答和任务结束等提醒，首次开启时允许系统通知。提醒需要服务端配置 Apple 推送；收不到时检查系统通知权限，再联系管理员核对。Android 通过打开应用、前台刷新及恢复连接查看任务更新。

清理下载缓存会移除本机下载副本，之后可以重新下载；清理前确认需离线使用的文件已另行保存。退出账号前保存需要保留的草稿和文件。

## 常见问题

| 情形 | 处理步骤 |
| --- | --- |
| 电脑不可用或列表为空 | 确认同一服务和账号、电脑在线及同步开启；刷新设备列表，再检查组织授权 |
| 操作结果待确认 | 保留当前请求，恢复联网后使用“核对结果”，核对期间暂停重复发送 |
| 排队或资源繁忙 | 等待原请求；持续等待时联系管理员检查模型容量 |
| 额度已预留 | 等待在途调用结算；预留金额在结果确认前占用可用额度 |
| 余额不足、每日额度用完或额度到期 | 在账号页面查看额度，联系管理员调整额度或有效期 |
| 原文件可下载、预览失败 | 保存原文件，检查电脑预览生成状态；需要时提交重新生成请求 |
| 模型配置异常 | 保留错误提示和任务内容，由管理员核对模型、凭证与额度 |

通过原下载入口或应用更新入口升级。反馈问题时提供客户端版本、系统、问题时间、操作步骤和脱敏截图；企业用户联系本组织管理员，公开体验用户使用官网客服入口。

项目许可及商业使用条件见[根目录许可说明](../README.md#许可)；具有独立许可声明的部分按各自许可使用。
