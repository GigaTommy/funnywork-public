# FunnyWork 管理员指南

**简体中文** | [English](ADMIN_GUIDE.en.md)

本指南用于开通成员、配置模型与额度、管理设备和组织策略，以及检查任务运行情况。管理页面由管理员角色权限和业务授权共同控制；首次部署、身份桥及凭证配置由交付人员按[开发与部署入口](../README.md#配置与部署)准备。

## 管理入口与职责

从交付人员提供的管理端地址登录。在“系统管理”维护用户和角色，在“工作平台”管理业务配置。

| 页面 | 主要用途 | 操作条件 |
| --- | --- | --- |
| 用户管理、角色管理 | 成员、部门、账号启停及功能权限 | 身份平台相应用户和角色管理权限 |
| 员工业务授权 | 为成员配置业务角色和授权区域 | 业务管理员身份及业务授权维护权限 |
| 模型配置 | 模型与容量、预算与计价、Agent 预设、客户端发布 | 模型读取／维护权限；全站预算和计价另由指定运营账号维护 |
| 客户端策略 | 成员设备、组织策略及应用回执 | 客户端读取／维护权限及对应业务范围 |
| 任务管理、会话历史 | 检查任务、执行终端、历史和成果 | 相应读取权限；正文、输入和产物按专项权限开放 |
| 执行资源、年报 | 配置业务执行资源，编制结构化年度经营摘要 | 对应模块权限及项目、区域授权 |

菜单缺失时，先由角色管理员核对功能权限；页面可见但操作被拒绝时，再检查业务角色和区域。业务授权页面只能分配当前管理员自身拥有的角色和区域。

## 开通一名成员

1. 在“系统管理 → 用户管理”创建或选择成员，设置账号、昵称、所属部门和角色，保存并保持账号启用。统一身份同步的成员由相应身份来源维护。
2. 在“角色管理”为该成员的角色授予“工作平台 → 客户端策略”下的“桌面客户端使用”权限。业务管理功能按职责单独分配。
3. 进入“工作平台 → 员工业务授权”，点击“配置授权”，搜索员工账号，选择权限模板、业务角色和授权区域，点击“保存”。一般任务操作可使用“任务操作与查看”模板。
4. 返回用户列表，点击该成员的“使用状态”，核对账号启用、桌面权限已授予、业务授权已授权及区域配置。
5. 按下一节配置可用模型和成员额度，再让成员在电脑登录并发送简短测试任务；手机使用同一账号验证聊天和电脑任务。

保存超时或列表刷新失败时，先返回列表和“使用状态”核对已有账号及授权，再决定是否重试。业务授权中的“撤销”用于停止业务访问；停用账号在用户管理中处理。

## 配置模型服务

进入“工作平台 → 模型配置”。“模型与容量”管理桌面推理部署，“客户端发布”维护手机聊天服务端入口使用的官方模型设置；两项配置分别保存和核对。

### 模型与容量

1. 打开“模型与容量”的容量池页，填写名称、区域、并发、队列及等待设置，创建或保存容量池。区域应与成员和业务授权一致。
2. 打开模型部署页，选择容量池和部署预设，填写名称、模型标识、协议、服务地址和凭证引用，核对上下文、最大输出及工具／图片等能力声明后创建。更换模型、地址或能力时创建新部署，再停用旧部署。
3. 让部署人员在服务端配置引用对应的凭证。表单填写凭证引用名称，密钥保存在服务端受限配置中。
4. 在“预算与计价”完成计费和额度配置，再从已授权客户端选择模型，发送简短文本请求。需要工具或图片输入时，分别验证相应任务。

容量池控制并发和排队，成员额度控制可消费金额。模型协议、工具调用和图片输入按部署配置提供，接入字段见[模型中间层参考](../services/business/MODEL_MIDDLEWARE.md)。

### 手机聊天官方模型

1. 打开“客户端发布”，填写模型名称、服务地址、思考模式、最大输出和凭证引用。
2. 点击“检查连接”，查看连接、凭证及模型发现结果。
3. 点击“发布新版本”，确认发布范围；在发布历史中核对新版本和参数，再通过手机聊天验证实际回复。
4. 需要恢复旧设置时，在历史记录点击“以新版本恢复”。恢复后继续按当前凭证引用读取密钥。

连接检查读取服务连接及模型目录，实际推理验证通过已配置额度的客户端完成。版本冲突时刷新并核对最新设置，再选择编辑基线。配置格式和加载机制见[模型发布参考](../services/business/MODEL_PUBLICATION.md)。

## 设置成员额度和全站预算

进入“模型配置 → 预算与计价”。金额以人民币元填写；每日预算按北京时间重置。

1. 指定运营账号在“模型计费”选择模型部署，按实际供应商配置计费方式、输入／输出价格上界及提供者最大输入 Token，保存。
2. 同一运营账号在“全站预算”设置累计、每日预算，核对“暂停全站推理”状态并保存。
3. 在“成员额度”选择成员并点击“读取”，设置累计预算、每日预算、额度有效期、跨设备并发、每分钟推理次数和单次最大输出，启用“允许使用”后保存。
4. 通过成员客户端发起简短请求，回到额度页面读取已结算和已预留金额，确认调用和计量正常。

成员“手工充值”增加累计额度；每日上限、有效期及允许使用状态需另行配置。充值结果待确认时使用“核对充值结果”，按原请求恢复。推广赠送在“推广赠送”中配置适用租户、方式、金额和发放上限，默认关闭。

推理先预留费用，完成后按实际用量结算。未确认的上游调用继续保留预留金额；由运营人员核对供应商结果后处理。价格和输入上界用于计算预留，应按真实配置审核。规则见[模型额度与预算](../services/business/MODEL_BUDGETS.md)。

## 管理电脑访问与组织策略

### 成员设备

1. 打开“工作平台 → 客户端策略”的“成员设备”，按设备或成员名称、状态查询。
2. 查看最近上报时间、客户端版本、模型状态和组织策略版本，点击“详情”核对设备信息。列表“在线”表示最近 30 秒内收到有效运行状态。
3. 需要阻止同步与远程控制时，点击“撤销访问”并确认。排队命令随之过期；已开始的本地操作需在电脑端确认并停止。
4. 恢复时点击“恢复访问”，让电脑重新连接，再刷新核对上报状态。过期指令保持失效。

设备撤销保留本地数据，成员其他登录会话的管理在账号系统处理。设备权限和状态字段见[成员设备管理](../services/business/MANAGED_DEVICES.md)。

### 组织策略

1. 在同页的组织策略区域设置“允许跨设备访问”“允许远程控制”、默认主题和语言。
2. 使用策略预览核对草稿与个人设置的组合结果，再点击“发布策略”。
3. 在发布历史核对版本，在客户端回执中检查获取和应用版本；离线设备在恢复连接后继续核对。
4. 需要恢复时选择“恢复为新版本”，重新检查回执。

关闭跨设备访问会阻止云端对话读取、连接码及跨设备操作；桌面仍可上传归档。关闭远程控制会拒绝新命令并使排队命令过期，已开始的操作继续在原电脑确认。主题和语言为默认设置，成员个人偏好按策略规则保留。详见[桌面组织策略](../services/business/DESKTOP_POLICY.md)。

## 检查任务、历史与成果

在“任务管理”选择任务，核对状态、当前尝试、等待原因和执行终端。等待资源时检查模型容量、额度、设备在线状态及执行资源授权；操作待确认时先核对原请求。任务接受回执、执行完成、文件上传和预览准备在各自阶段查看。

“会话历史”提供目录检索和按授权查看正文。目录读取、正文读取及产物读取分别受权限控制；为承担支持职责的角色单独分配所需权限和业务范围。成果异常时保留原文件及版本，核对上传状态、大小和转换字体，必要时要求电脑生成新版。

## 配置业务执行资源与年报

仓库维护在“任务管理 → 代码维护”的问题与仓库入口配置。在“执行资源”依次准备项目、资源池、成员、用途、项目授权和路由，再用“终端预览”查看候选与排除原因。仓库开发和验证使用对应用途，任务详情的“执行终端”显示实际分派记录。配置步骤和字段见[执行资源管理](../services/business/EXECUTION_RESOURCES_R4.md)，自动维护见[运行与配置参考](../services/business/MAINTENANCE_AUTOMATION.md)。

“年报”用于依据结构化收入、成本和上年收入资料编制固定模板经营摘要。创建资料快照，配置同项目的 COMPILE 用途、资料授权及路由后发起编制，查看核验结果并下载正式文件。资料修订时新建快照；指标口径与输出格式见[年报参考](../services/business/ANNUAL_REPORTS_R5.md)。

## 升级和支持

交付人员提供业务服务、身份服务、管理前端和客户端的版本清单及恢复方法。按[客户端发布与升级](../deploy/CLIENT_RELEASES.md)安排更新，升级后检查成员登录、模型调用、手机连接和代表性成果流程。

排障时记录问题时间、组件版本、成员和任务编号、脱敏错误及已完成的核对步骤。配置提交成功后若刷新失败，先读取当前状态再操作；跨成员、模型或策略的版本冲突需重新核对最新值。

项目许可及商业使用条件见[根目录许可说明](../README.md#许可)；具有独立许可声明的部分按各自许可使用。
