# FunnyWork 手册

**简体中文** | [English](README.en.md)

按使用身份选择入口。客户手册说明日常操作；开发与部署文档说明系统如何构建和维护。平台条件和任务步骤见使用指南，管理员配置见管理指南。

| 读者 | 从这里开始 | 可解决的问题 |
| --- | --- | --- |
| 员工与体验用户 | [使用指南](USER_GUIDE.md) | 登录、换头像、发起任务、查看进度和成果 |
| 企业管理员 | [管理指南](ADMIN_GUIDE.md) | 配置成员、权限、模型与额度，处理连接和执行异常 |
| 升级用户 | 下方版本记录及官方下载安装入口 | 查阅指定版本的变化与升级要求 |
| 开发人员 | [开发 README](../README.md)、[贡献指南](../CONTRIBUTING.md) | 准备环境、修改源码、运行检查和维护文档 |
| 交付与运维人员 | [自建服务部署](../deploy/SERVER_DEPLOYMENT.md)、[客户端发布与升级](../deploy/CLIENT_RELEASES.md) | 分发安装包、维护更新通道、验证入口与回退 |
| 发布负责人 | [版本说明模板](../deploy/RELEASE_NOTES_TEMPLATE.md) | 准确说明一个版本交付了什么、谁需要升级 |

企业内部署由交付人员提供服务地址、账号开通方式和对应版本资料。客户安装对应客户端后即可使用，无需准备代码开发环境。
