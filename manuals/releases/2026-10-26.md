# FunnyWork 客户端更新

2026 年 10 月 26 日，官网开放以下预发布版本下载：Mac 0.2.1-alpha.1.20261026.1（Apple Silicon / Intel）、Android 0.1.0-rc.4（构建号 14）。

本说明对比 Mac 0.2.1-alpha.1.20261024.2 和 Android 0.1.0-rc.3。

## Mac

- 额度被在途任务占用时，等待提示更清楚。
- 修复读取整页图表后任务可能中断的问题。
- 改进新建 Word 文档的字体设置，减少 PDF 预览中的字体替换。历史文件如需改善排版，可重新生成并发布新版。

## Android

- 远程入口显示电脑连接状态，任务中可核对电脑和工作区。
- 点击头像选择图片，保存后同步到同账号其他客户端。
- 改进任务消息搜索、未读提示和创建结果恢复。
- 修复较长任务记录未能显示最终回复的问题。

## 升级

从原官方入口下载安装，Android 可覆盖旧版，保留账号和已有记录。Mac 延续 nightly 预发布更新通道。Windows 下载状态和 iOS TestFlight 邀请保持原配置。各端高级功能仍存在差异，升级不会将历史文件自动改写。

下载与客服入口：[官网](https://funnywork.funnypixelsapp.com/download/?lang=zh)。

# FunnyWork client update

October 26, 2026. Prereleases available from the website: Mac 0.2.1-alpha.1.20261026.1 (Apple Silicon / Intel) and Android 0.1.0-rc.4 (build 14).

Changes below are relative to Mac 0.2.1-alpha.1.20261024.2 and Android 0.1.0-rc.3.

## Mac

- Clearer waiting messages when ongoing tasks have reserved your available allowance.
- Fixed an issue that could interrupt a task after reading a full-page chart.
- Improved font settings for newly created Word documents to reduce font substitution in PDF previews. Regenerate and publish a new version to improve an existing document's layout.

## Android

- See your computer's connection status and confirm where a task will run.
- Choose a profile picture from your avatar and sync it across devices on the same account.
- Improved task message search, unread indicators and recovery after creating a conversation.
- Fixed missing final replies in longer task histories.

## Upgrading

Use the original official download page. Android supports upgrading the existing installation while retaining the account and saved records. Mac continues to use the nightly prerelease channel. Windows availability and the iOS TestFlight invitation remain unchanged. Advanced features still vary by platform; upgrading does not rewrite historical files.

Downloads and support: [Website](https://funnywork.funnypixelsapp.com/download/?lang=en).
