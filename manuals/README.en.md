# FunnyWork manuals

[简体中文](README.md) | **English**

Choose an entry point for your role. User manuals cover daily work; development and deployment references cover building and maintaining the system. The user guide explains platform requirements and task steps, while the administrator guide covers configuration.

| Reader | Start here | Topics |
| --- | --- | --- |
| Members and evaluation users | [User guide](USER_GUIDE.en.md) | Login, avatars, tasks, progress, and results |
| Organization administrators | [Administrator guide](ADMIN_GUIDE.en.md) | Members, permissions, models, allowances, and connection/execution issues |
| Upgrading users | Release records below and the official download entry point | Changes and upgrade requirements for a particular version |
| Developers | [Development README](../README.en.md), [contribution guide](../CONTRIBUTING.md) | Environment setup, source changes, checks, and documentation |
| Deployment and operations teams | [Self-hosted deployment](../deploy/SERVER_DEPLOYMENT.md), [client releases and upgrades](../deploy/CLIENT_RELEASES.md) | Installers, update channels, verification, and rollback |
| Release owners | [Release notes template](../deploy/RELEASE_NOTES_TEMPLATE.md) | What a version delivers and who should upgrade |

For organization deployments, deployment staff provide the service address, account setup process, and version materials. Users install the matching client without preparing a source development environment.
