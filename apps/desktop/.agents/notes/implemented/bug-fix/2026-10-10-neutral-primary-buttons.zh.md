# Agent Note：中性主按钮对比度

Status: implemented

[English](2026-10-10-neutral-primary-buttons.md) | 中文

## 问题

浅色主题使用淡蓝主按钮与深色文字，偏离项目的中性主操作方向，也与已稳定的 Settings 外观快照不符。

## 决策

主按钮底色恢复为主题拥有的既有中性品牌别名，文字恢复为白色。悬停使用既有深色中性调色板，深色模式别名保持不变。共享按钮与账号充值链接消费同一组别名。

## 验证

Settings 浏览器回归对比两套主题的既有外观快照，并独立测量静止与悬停状态的实际文字对比度和底色中性程度。模型保存操作也检查实际文字对比度。既有焦点回归覆盖键盘与鼠标焦点绘制。

全量 Web 检查还发现旧夹具中的欢迎语、返回按钮与插件警告文案过期，相应断言已同步当前文案和正式品牌图案。首页身份断言区分 FunnyWork 构建与默认预览构建。Web 安装元数据采用设计规范中的客户端名称 FunnyWork。

重载检查等待 Host 引导步骤持久化，因为可见步骤是乐观预览。流式回放重载等待启动目录查询完成，未捕获的页面错误仍导致失败。空会话夹具在释放写入者前提交冷列表元数据。排队发送等待客户端运行状态。终端检查观察浏览器退出帧及所属进程完成。会话拒绝检查明确指定已准备的工作区。草稿导航使用平台原生的文档与行快捷键。任务结束快照等待客户端离开运行状态。插队回放使用明确的流同步点，在观察到排队接纳后继续。模型编辑器等待凭证和保存后的目录刷新，再重新打开。上传开关的重载检查等待输入框可编辑；子任务导航在打开菜单后使用键盘入口。终端启动用拆分字符串的就绪探针验证命令执行，不依赖第一帧 Shell 提示符。队列快照等待流式文本出现。预设目录检查先确认正向条目加载，再断言命令移除。恢复与权限重装检查等待客户端列表及目录就绪。ARIA 稳定性比较通过所属 MessageChannel 跨越浏览器任务，兼容暂停模拟时钟的场景。已充值快照在进入额度步骤前观察 RPC JSON 读取并跨越浏览器任务，再等待余额决定的按钮，空会话重载等待列表检查点持久化，检查器录制观察启动与停止回执。最终对话等待完成投影，提醒刷新与文件打开能力等待加载完成。语言快照限定已选择语言的弹窗，连续目标快照建立约定的滚动位置。终端补全检查区分执行输出与输入回显，并观察重命名回执；调色板检查等待实际字形颜色更新。长对话滚动检查等待工具进入运行状态。上下文布局发送等待逐次接纳回执，重载后的工作区操作等待恢复后的输入框可编辑，快速交接夹具在阻塞后续历史帧前等待种入的完成投影。这些等待保留功能断言，不接受未稳定快照，也不放宽超时。

## 考虑过的替代方案

**把快照刷新成蓝色主题。** 这会接受视觉回归，而不是恢复文档约定的中性外观。

**逐个覆盖按钮样式。** 局部覆盖会让其他消费者继续不一致，因此修正在共享主题中完成。

## 影响

业务组件无需增加局部颜色覆盖。既有快照继续表示预期的中性外观，不为意外的蓝色配色刷新快照。
