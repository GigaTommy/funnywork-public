# FunnyWork 服务选路

[English](guide.md) | 中文

## 变更

两个官方 HTTPS 地址通过无凭证可达性探测，在国内和海外入口之间自动选择。原海外 origin 继续作为稳定账号身份。登录页显示连接状态，不再显示配置域名。显式自建服务继续隔离，不使用官方备用入口。失败的写请求和模型流不会自动重发。

## 迁移

1. 更新桌面客户端，不编辑 `funnyworker-account.enc`、Session 文件或已有账号目录。已有官方登录凭证仅在验证服务端账号身份后使用。
2. 已有国内不可变账号映射改归稳定官方命名空间，原目录保持不动。两份不同历史不会合并或覆盖。手工处理冲突映射前保留备份。
3. 保持自建服务配置不变。两个官方地址都启用自动选路，均不代表强制地区设置。
4. 在真实大陆无 VPN 网络和国际网络分别验证登录、历史、模型流及恢复。临时断网保留已存凭证并报告连接失败，不删除凭证或重放执行。
