# Funnywork 当前服务协议

[English](guide.md) | 中文

## 变更

Funnywork 桌面要求账号会话返回非空 `principalId`，提供当前组织策略并开启计量推理。缺失接口或协议文档时明确失败，不再选择旧协议。移除客户端共享模型密钥、签名密钥发布和直连供应商续期；模型凭证、预算和准入统一由服务端管理。新账号目录使用主体身份；已有目录映射继续作为数据定位信息，不删除现有数据。

## 迁移

1. 从 funnyworker 仓库同一当前版本更新 `services/business/` 与桌面客户端。
2. 保留 `.local/` 和账号数据。新客户端不应搭配旧服务接口部署。 如果存在与账号名关联、尚未映射的本地工作区，登录后在恢复对话框中确认所有权。客户端会再次核验已认证身份，然后记录目录映射；取消不会修改文件或映射。文件保留在原目录，后续登录复用已记录的映射。
3. 验证登录、组织策略回执、模型额度及计量模型响应。不支持的响应必须报错，不能静默关闭功能。
