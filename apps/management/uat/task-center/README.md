# 组织任务组件验收

**简体中文** | [English](README.en.md)

使用生产 `ManagementTasks.vue`，仅替换接口为虚构数据。不连接身份服务或生产数据库；不能以本页面证明实际授权、完整管理壳、迁移、生产发布或跨端任务聚合通过。

在仓库根目录运行（使用已有管理端依赖，不自动安装）：

```sh
~/.codex/bin/with-external-storage --project "$PWD/apps/management" -- corepack pnpm exec vite --config uat/task-center/vite.config.mjs
```

打开 http://127.0.0.1:19194/ 。按负责人选择并查询，检查列表/汇总一致；检查浅深色、详情、空数据、503、403，以及恢复正常后重试。异常模式只在下一次请求生效。慢请求模式可检查忙态。测试结束关闭临时窗口和服务。

服务端真实查询、身份权限映射、分页、租户/区域隔离与内容投影由 `ManagementTasksIntegrationTest` 验证；不要将接口桩的 403 冒充真实撤权。本地实施和验收记录按[贡献指南](../../../../CONTRIBUTING.md#配置与数据)归档。

## 第二批验收边界

新增部门/项目筛选、业务归属编辑、执行终端、管理范围配置、单任务暂停/恢复/取消预览和响应丢失回执测试。入口的权限均为虚构测试权限，不配置真实管理员或生产身份源。

“命令提交后响应丢失”模式只在模拟 POST 命令首次返回时注入 503，模拟回执可随后查询；它证明页面核对流程，不证明网络真实断线或服务端物理停止。模拟后端状态在页面重载时重置；不可用该桩验证服务端持久性。持久待核对记录按站点、租户与账号隔离；存储恢复/不可替换原请求由 pending-task-command 测试覆盖，真实数据库幂等由 ManagementTasksIntegrationTest 覆盖。

目录大分页、跨范围拒绝及 UNKNOWN 外部操作取消保留核对由后端隔离测试验证，不能把本工具的权限模式当作真实撤权证据。完整管理壳、生产 PostgreSQL 与真实终端仍另行验收。

## 后续批次验收

新增本地成员部门配置与不可变创建归属、独立输入/文件授权、批量固定集合确认及原请求回执、验收/交付元数据。URL 的 tc_* 参数支持查询和详情恢复；不复用个人任务原 taskId/state 参数。

批量预览会排除不适用状态；“命令提交后响应丢失”也覆盖批次模拟 503，核对回执后清除待核对记录。此处浏览器刷新仍会重置模拟服务端记录，因此数据库持久性、事务回滚、并发幂等以 ManagementTasksIntegrationTest 和独立 PostgreSQL 测试为准。输入使用普通文本插值显示，目录不在页面执行或内嵌预览文件；原始字节与关联边界由真实 HTTP 测试验证。

验收／交付面板分别展示产出、验收与交付状态；内容未授权时显示权限提示，面板沿用原用途协议，不提供单独的成功覆盖操作。完整壳权限、跨工作台往返与真实撤权在对应的隔离服务中验收。

完整管理壳需在独立身份/业务服务中另行验收并保存本地记录。本目录用于组件夹具，不把其结果替代真实链路。
