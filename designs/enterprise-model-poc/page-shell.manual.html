FunnyWork
企业模型 POC · 本地工具

先识别接口，再验证能力

只有统一认证和模型聊天网页，也能从一次测试对话开始。用已登录页面采集请求，回到这里分析；不需要 Python、PowerShell 或安装插件。

01 / 在聊天页采集

沿用你的登录状态

正常登录模型聊天页，按 F12 打开 Console。复制采集脚本并执行，再发送一句不含业务信息的测试消息。

02 / 导出并导入

只看需要的信息

在聊天页 Console 执行下面的命令，将生成的 JSON 导入右侧。也可以导入浏览器导出的 HAR。

FunnyWorkPOC.download()

采集不导出凭证或聊天正文。HAR 仍可能包含这些内容，请在内网本地处理。

03 / 手动验证

从一条基本对话开始

选中识别到的标准接口，复制测试命令，到原聊天页 Console 执行。会发送合成内容并消耗模型额度；默认不做批量或并发测试。

FunnyWorkPOC.stop()

结束后执行 stop，或刷新聊天页，恢复原页面请求方法。采集最多持续 5 分钟。

在已登录的模型聊天页运行
下面的脚本由本工具提供，不会尝试登录。仅在你有权使用的模型聊天页执行，使用完成后 stop 或刷新。它只观察之后的 Fetch/XHR 请求，不读取浏览器凭证库；执行测试时可临时复用观察到的同源请求认证头，凭证不写入报告。
